# Jagan Mohan — Engineering & Technology Portfolio

A recruiter-first static portfolio for Jagan Mohan, focused on telecom/GIS design, engineering workflows, automation and selected technical projects.

## Stack

- Plain HTML5, CSS3 and vanilla JavaScript
- No framework or build step
- SVG/CSS engineering visualizations
- Responsive layout with mobile navigation
- Persistent dark/light theme

## Portfolio URL

https://mr-jaganmohan.github.io/portofolio/

## Local development

No package installation is required. Serve the repository with any static web server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

Opening `index.html` directly also works, but a local server is recommended for browser testing.

## GitHub Pages deployment

The repository is intended to publish from the `main` branch using GitHub Pages. No framework build step is required, and `.nojekyll` is included.

Repository path:

`MR-JAGANMOHAN/portofolio`

## Content sources

Portfolio content is limited to known profile/project information. No fake testimonials, fabricated statistics, credentials or companies are used.

The featured URL Shortener Bot V2 entry is based on the project's public README and links to its source repository.

## Resume

A resume PDF is not currently stored in this repository, so the Hero "Resume" action opens an email request rather than linking to a nonexistent file.

## Accessibility / performance

- Semantic HTML landmarks and heading structure
- Keyboard-accessible navigation and theme controls
- `prefers-reduced-motion` support
- No API calls required by the page
- No frontend secrets or API tokens
- Lightweight static assets
