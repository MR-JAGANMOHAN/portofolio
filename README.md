# Jagan Mohan — Engineering Portfolio

A custom static portfolio focused on telecom design, GIS, FTTH/FTTX, utility mapping, CAD, pole validation and QA/QC delivery.

## Design direction

The interface uses a glass/technical visual system with engineering-specific animations: permit layers, ROW/EOP geometry, fiber route flow, pole/load visualization and delivery connectivity.

The structure is inspired by the clean static architecture and interaction philosophy of modern open-source portfolio projects, including `snig-17/portfolio`, but the content and visual system are custom-built for Jagan Mohan's engineering work.

## Deployment

Designed for GitHub Pages from the `main` branch.
